## 1. 한눈에

- 정령 = 조각 4개(head·torso(발 포함)·팔 2) × 방향 3(front·side·back, 왼쪽 = side 좌우 뒤집기) = 12조각 + 자기 그림 1장(front).
- 정령은 걷지 않고 떠 있다. 몸은 땅(발 기준선)에서 몸 키 × `floatHeight`(0.15)만큼 위, 그림자는 땅에.
- 키 = 동행 키 × `scaleToCompanion`(0.75). 동행 그림 크기는 그대로, 정령을 줄인다.
- 포즈 = 클립의 키마다 조각별 `{dx, dy, rot, sx, sy}`. 동작 10, 표정 6은 동작 위에 따로 얹음.
- 옷·소매 = 조각과 같이 움직이는 덧층. 신발은 몸통 아래 덧층(발이 몸통에 붙음). 모자·얼굴 소품·가방·장갑 = 앵커에 붙는 한 장.
- 몸 색은 조각의 `fill` 마스크에만 곱한다. 얼굴은 v24 파츠, 뒷면은 얼굴 숨김.

## 2. 좌표·크기

| 항목 | 값 |
|---|---|
| 캔버스 | 1024×1024, 가운데 x 512, 떠 있기 기준 발 아래 끝 y 960, 머리 꼭대기 ≈ 192(몸 키 768) |
| 회전 | 도, + = 시계방향. 정면 armL은 + 가 바깥, armR은 − 가 바깥 |
| 변환 순서 | 피벗 중심 sx·sy → rot → (dx, dy), 그 위에 부모. root → torso → head·armL·armR(옆: armNear·armFar) |
| 키 사이 | 직선 보간(앱이 ease를 더해도 됨) |
| 제한(앱 테스트도 검사) | 팔 0°~±150°(위아래만), 몸통 ±8°, 머리 ±6°, sx·sy 0.85~1.12 |
| 떠 있는 높이 | 몸 전체를 위로 `floatHeight × 768` = 115(1024 좌표). 클립의 root dy는 그 위에 더함 |
| 화면 키(가안) | 세로 344px·가로 259px = 동행 화면 키 × 0.75. 동행 화면 키 = 540 × 0.85 = 459px(추정, 아래) |
| 화면 배율(가안) | 344 ÷ 768 = 0.448(세로), 259 ÷ 768 = 0.337(가로) |
| 떠 있는 높이(화면) | 세로 52px·가로 39px(화면 키 × 0.15) |

동행 키 기준: 동행은 1024 캔버스에 정령 v25와 같은 배율로 들어 있고, 지금 규칙은 '동행 키 = 정령의 80~90%'(boats.json)라서 가운데 0.85를 씀 → 1024 좌표 약 653(추정). Codex v06 `qa/with_companions.png`(T11)에서 v15 세 동행 키를 재서 `character.float.companionCanvasHeightPx`를 고친다(세 동행 키가 다르면 셋의 평균, 화면에서는 정령 키 하나).
config 값은 `character.float`에 따로 두고, T5에서 바꿀 때 `canvas.screenHeightPx`·`scene.characterHeightPx`·`camp_wide.character`로 옮긴다(그전에 바꾸면 Rive 정령이 바로 작아짐).

앱 넣는 판: 0.75배 대신 화면 배율(0.448)에 맞춘 0.5배 + 투명 여백 자르기를 추천(1024의 0.5 = 512, 화면 344px보다 크고 3배 폰 기준 여유. 추정). 자른 자리 `trim: [x, y, w, h]`(1024 좌표)는 개발 내보내기 스크립트가 json에 씀. 피벗·앵커는 1024 좌표 그대로.
메모리 추정: 한 방향 조각 4 + fill 4 + 여행복 덧층 neutral·detail 약 6장, 0.5배·잘라 낸 한 장 평균 0.15~0.25MB(추정) → 한 방향 약 2~3.5MB, 세 방향 + 자기 그림 약 10MB. v0.2(약 25MB)보다 작음.

## 3. spirit_float.json (앱이 읽는 키)

v06 지시서 6장 파일 이름 규칙 + v0.2의 json 모양. 앱은 아래 키만 읽고 나머지는 무시한다.

```json
{
  "version": 1, "canvas": [1024, 1024], "feetY": 960,
  "scaleToCompanion": 0.75, "floatHeight": 0.15,
  "shadow": { "w": 0, "h": 0, "minScale": 0 },
  "pieces":  { "<dir>": { "<pieceId>": { "file", "fill", "parent", "pivot": [x, y], "trim"? } } },
  "anchors": { "<dir>": { "<anchorId>": { "piece": "<pieceId>", "at": [x, y] } } },
  "face":    { "front": { "anchor": "faceCenter", "layout", "faceScale", "faceOffset": [dx, dy] }, "side": {…}, "back": null },
  "order":   { "<dir>": ["<층 이름>", …] },
  "specials":{ "sleep": { "torso": "spirit_float_front_sleep_v06_clean.png", "fill": "…_fill_…", "cloth": {"neutral", "detail"} } },
  "clips":   { "<clipId>": { "dir", "fps", "loop", "keys": [ { "<pieceId>|root": {dx, dy, rot, sx, sy}, "face": "<표정>", "special": null } ] } },
  "hit"★:   { "<dir>": { "head": {"piece": "head", "cx", "cy", "rx", "ry"}, "belly": {"piece": "torso", …} } }
}
```

- pieceId: `head`·`torso`·`armL`·`armR`(front·back), `head`·`torso`·`armNear`·`armFar`(side). `footL`·`footR`·`footNear`·`footFar`는 없음 — 있으면 앱이 무시하고 경고.
- `shadow`: `w`·`h` = 떠 있기 기본 자리 그림자 타원 폭·높이(1024 좌표), `minScale` = 가장 높이 떴을 때 그림자 크기 비. 그림자는 앱이 땅(feetY)에 타원으로 그림(그림 파일 없음). root dy가 위로 갈수록(− 쪽) 1 → minScale로 줄임. v06에 값이 없으면 ★ 기본값 `w 300, h 48, minScale 0.8`(추정).
- `special`: 자기 키 동안 torso 그림(과 fill·옷 덧층)을 자기 그림으로 바꿔 끼움. 자기 그림은 팔·머리가 그림 안에 있으면 그 키에서 head·팔 조각을 숨김(`hide: ["head","armL","armR"]` ★, 없으면 앱이 숨김).
- 조각 키에 없는 값은 0(dx·dy·rot)·1(sx·sy).

- 뺀 것: fall(넘어지기, 11/6), sit 2·lie·run·spread(11/9). 앱 코드에서 이 이름을 부르는 곳은 위 표 오른쪽대로 바꾼다. 울먹임은 동작 없이 표정 '눈물'만(동행 이야기 감동·오래 쉬다 돌아옴).
- 한 번 동작(greet·joy·press·angry)이 끝나면 장면 기본 클립(float_*·move_side·sleep_front)으로 돌아감.
- 방향(config `character.facing`): rest·customize·profile·arrival front, walking·running side, departMoment·splash·viewScenery back. fall·sit 키는 v12에서 지움.
- v06에 클립 id가 다르게 오면 앱은 이 표 이름으로 고친 사본을 내보내기 스크립트에서 만든다(추천: 디자인 기획이 v06 보완에 이 id를 적음).

## 9. 앱 쪽 (개발, T5)

- `SpiritCutout` 위젯은 v0.2 9장 그대로 + 떠 있기 lift·그림자 타원. 걷는 중 이동은 정령 화면 x 고정, 배경이 움직임(지금과 같음).
- 배: 그림자 = boats.json mainFoot(갑판), 몸 = 그 위 lift. 동행은 companionFoot 그대로.
- 쉼터: themes/camp_wide.json `characterFloat`(가안 x 46·w 92·키 115pt·그림자 y 725·lift 17pt)를 T5에서 `character`로.
- 이야기 그림: story_layers.json `playerResize` 규칙(장면별 동행 키 × 0.75 ÷ 768). 장면별 동행 키를 재기 전까지 v2 scale 그대로.
- 완료 기준: 중급 안드로이드 쉼터·걷는 중 60fps, 정령 이미지 메모리 +15MB 이하(추정 목표), 세 방향 미리 읽기.
- 테스트: `cutout_render.py`와 같은 행렬(소수 3자리), 발 조각이 있으면 경고, 제한 밖 값이면 실패, 몸 색이 얼굴·옷에 안 묻음, 그림자가 lift와 반대로 줄어듦, 클립 10개 id가 7장 표와 같음.
