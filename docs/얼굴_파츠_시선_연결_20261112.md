# 확정 PSD 얼굴·시선 연결 (2026-11-12)

- 게임 파일 `app/assets/rive/doobal_unified.riv`: 투명 바탕, 통합 v04. 몸·팔·다리(v18 옆앉기 포함)·소품37종과 기존 동작 곡선을 보존했다.
- `eyeStyle`: 기본0·순한1·장난2·졸린3·감은4·반짝5.
- `browStyle`: 없음0·둥근1·짧은2·화난3·졸린4·걱정5·미남6.
- `noseStyle`: 빗금0·고리1·위곡선2·아래곡선3·두점4·옆곡선5·동글6·없음7.
- `mouthStyle`: 미소0·오메가1·송곳니2·벌림3·활짝4·긴미소5·살짝6·큰미소7.
- 기본 조합은0/1/6/6으로, 기존 확정 기본 얼굴과 같다. 파츠 PNG는 확정 PSD 내보내기 원본이며 다시 그리지 않았다.

## 게임과 저장

`face_parts.dart`·`palette.json`의 목록을 PSD와 맞추고, 기존 `Look`의 문자 id 저장과 `ProfileService`를 그대로 사용한다. 시작·꾸미기·쉼터·걷는 중·나의 정보가 같은 얼굴 입력을 쓴다. 37소품 선택·소품색·몸색은 별도이며 얼굴 변경으로 초기화하지 않는다. DB 스키마 변경 없음.

기존 저장 id는 읽을 때 대응한다. 예: dot→default_drop, bean→soft, cat→mischievous, fierce(눈)→sleepy, shiba→gentle, thick→handsome, fierce(눈썹)→angry, shy→slash, dot(코)→round, heart→scoop, o→open, tongue→grin, flat→soft_smile. 새 PSD에 없는 예전 모양은 가까운 파츠로 대응하며 원래 게임 소품·색·프로필은 보존한다. 전체 대응은 `face_parts.dart`의 `legacyFaceAliases`에 있다.

## 시선과 반응

- `lookX`·`lookY`는 각각−1~1. 열린 검은 눈은 원본 좌표 최대4×3px, 테두리 있는 눈동자는3×2px만 움직인다. 머리·눈썹·코·입·모자는 움직이지 않는다.
- 감은 눈과 잠들기 눈은 시선 고정. 게임에서는 마우스·손가락 움직임에 따라가고, 벗어나거나 손을 떼면 중앙(위젯의 기본 시선)으로 복귀한다. 시선은 순간 상호작용이라 프로필에 저장하지 않는다.
- 고른 얼굴 값은 인사·기쁨·화남·눌림·잠들기 후에도 유지된다. 기쁨·화남에는 확정 눈·입 표정이 잠깐 우선하고, 코 선택과 눈썹 없음은 반응 중에도 유지된다. 잠들기는 감은 눈·쉬는 눈썹을 쓰되 눈썹 없음·코 선택·입 선택을 유지한다.
- Rive 검토판 오른쪽의 얼굴 부위와 시선 단추로 직접 비교할 수 있다. 게임용 내보내기에는 검토 단추가 없다.

## 검증 범위

모든 파츠 선택·정면/옆면/앉기/잠들기·시선 끝값·클램프·감은눈 고정·반응 복귀를 실제 Rive 렌더로 확인한다. 게임 파일 DB를 닫았다 다시 열어 얼굴·소품·색 복원을 검사하고 Android API35 분리 설치본 `com.annieha.doobal.integration`에서 게임 꾸미기 선택·저장·프로세스 재실행·시선 이동을 확인한다. 실제 게임 앱을 강제 종료하거나 덮어쓰는 설치는 하지 않는다. 실제 휴대폰 확인·배포·커밋/push는 별도다.
