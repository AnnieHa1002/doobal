## 판단 (개발 판단, 다르면 말해 주세요)

1. **쓰다듬기는 정령 몸 위에서 시작한 좌우 끌기만.** 정령을 놓는 600 캔버스 상자는 정령보다 훨씬 넓다(쉼터 정령 키 180pt면 약 372pt 정사각, 계산). 상자 전체로 받으면 쉼터를 거의 못 민다. 몸 위에서 시작한 좌우 끌기는 장면을 밀지 않는다(T15 누르기 순서 ‘집은 물품 > 앞쪽 물품 > 정령 > 장면 밀기’), 몸 밖은 그대로 장면 밀기.
2. **방향이 바뀐 것 = 4pt 넘게 되돌아감**(손 떨림 거르기, 화면 구성값이라 코드 상수). 처음 쪽은 바뀜으로 안 센다: 오른쪽 → 왼쪽 → 오른쪽(바뀜 2번)이 0.6초 안이면 쓰다듬기. 되면 센 것을 비우고 다시 센다.
3. **기울기는 쓰다듬기가 된 순간 문지르던 쪽으로 바로 4°, 0.3초 동안 0으로**(끝에서 느려짐, easeOutCubic). config에 기우는 시간이 없어 바로 기울였다. 기울이는 중에 또 되면 처음부터(repeat).
4. **쓰다듬기 표정은 Rive 입력 없이 expr만**(정령 계약 4장). 밤에도 1초 행복 뒤 다시 졸림. 연타 화남 셈(tapRules)에는 안 들어간다. 손가락이 가로로 움직여야 끌기가 이기므로 짧게 누르기·길게 누르기는 그대로.
5. **움직임 줄이기면: 쓰다듬기는 표정만(기울지 않음)**, 흔들림·수레는 움직임 없이 끝 상태. 표정은 움직임이 아니라 상태라고 봤다.
6. **흔들림 degs [6, 3, 0]은 차례로 닿는 각도 크기, 좌우를 번갈아**(+6 → −3 → 0, 캔버스 메모 ‘±6° 0.4초’). 칸마다 같은 시간(0.4 ÷ 3초), 칸 안은 사인으로 부드럽게. 첫 쪽은 오른쪽(시계 방향).
7. **등불 밤 빛은 같이 흔들지 않는다**(0.4초, 6°라 빛 자리 차이가 작음). 밤 빛은 장면 맨 위 층이라 따로 움직이려면 한 줄 더.
8. **수레 ‘한 번’ = 상점을 본 시각 기준.** DB에 새 칸이 없어 기존 `sync_state.shop_seen_utc`를 쓰고, 열 때마다 적게 바꿨다. 새 상품 점은 그대로 돈다(그날 5시 뒤 처음 열면 꺼짐).
9. **새 칸 = 지난번 본 날의 칸 수(그 수레 날 전날까지 거리) 이상 번호의 칸.** 50km를 넘긴 다음 날 바로 안 열고 며칠 뒤 처음 열어도 그때 한 번 돈다. 상점을 한 번도 안 연 사람은 설치한 날(3칸) 기준.
10. **차례는 이어 붙임**: 자물쇠 흐려짐 → 물건 톡(합 0.45초), 물건 빠짐 → 도장(합 0.45초). config에 사이 시간이 없어 바로 이었다. 물건 떨어짐은 빨라지게(u²), 떠오름은 느려지게, 도장 크기는 고르게. 도장 투명도는 처음부터 config 88%.
11. **산 칸의 꼬리표는 사는 순간 없어진다**(T16 칸 모양 그대로, 도장 칸은 꼬리표 없음). 떠오르는 것은 그림만. 새 칸은 꼬리표가 처음부터 보이고 그림만 떨어진다.
12. **새 칸이 도는 0.45초에도 누를 수 있다**(구매 시트). 팔린 칸은 도는 중·뒤 모두 누름이 없다(칸에 onTap 없음, 그림은 IgnorePointer).
13. **쉼터 수레 위 물건**(T16 `CartItemsOnTop`)은 팔려도 연출 없이 빠진다(config cartSlot.screen이 shop).
14. **④ ‘럭 숫자’ = 떠오르는 ‘+n 럭’의 숫자** — **Annie 확인(11/21): 가안대로**(통합 세션 경유, 원본 문서 ④는 따로 안 옴). 튀는 때는 캔버스 메모 ‘0.3초 동안 올라가며 1.15배 튀김’대로 오르는 0.3초 동안 1 → 1.15 → 1(가운데가 가장 큼)이다. 통합 세션에 처음 보낸 가안 글에는 ‘끝에 1.15배 튐’이라고 잘못 적었는데, config dropPickup에 끝에 튀는 시간 값이 없어 코드는 고치지 않았다(끝에 튀게 바꾸려면 시간 값 하나가 필요). 걷는 중 화면에 럭 잔액 칸이 없어 새 칸을 만들지 않았다(만들면 기획 변경). 숫자는 한 방울 몫부터 센다(0부터 세면 한 방울일 때 0.3초 동안 ‘+0 럭’이 보임). 전에는 한꺼번에 여러 방울을 주워도 ‘+1 럭’이었는데 이제 ‘+n 럭’(n = 방울 수 × coinsPerDrop, 실제 럭은 전처럼 물감 길 거리로 따로 셈).
15. **③ oncePerUnlock은 true만 안다**(false면 FormatException, 여는 때마다 돌리는 규칙이 아직 없음).

## 폰에서 볼 것

- 쉼터: 정령 몸을 좌우로 빠르게 두세 번 문지르면 웃으며 문지르는 쪽으로 살짝 기울었다 돌아오는가. 천천히 문지르면 아무 일 없는가. 정령 둘레(몸 밖)에서 끌면 쉼터가 밀리는가, 몸 위에서 끌면 안 밀리는가(판단 1). 짧게 누르기(머리·배)·연타 화남·길게 눌러 꾸미기가 그대로인가.
- 쉼터 꾸밈 물품(벤치·화분 등): 누르면 밑동을 축으로 좌우로 한 번 흔들리는가(0.4초). 꾸미기를 열면 눌러도 안 흔들리고 고르기만. 이젤·빨랫줄은 지금처럼 그림.
- 걷는 중: 방울을 주울 때 머리 위 ‘+1 럭’이 톡 튀며(1.15배, 오르는 0.3초 동안) 떠오르는가, 통 방울이면 통 아이콘이 살짝 늦게(0.1초) 붙는가. 화면을 끄고 걷다 켜면 ‘+n 럭’이 1씩 오르는가.
- 설정 ‘움직임 줄이기’(안드로이드 접근성 ‘애니메이션 삭제’)를 켜면: 물품은 안 흔들리고, 정령은 웃기만, 수레는 바로 도장, ‘+n 럭’은 튀지 않고 바로 다 오른 숫자.
- 상점: 칸을 사면 물건이 위로 떠오르며 사라지고 SOLD 도장이 크게서 작게 찍히는가. 상점을 나갔다 들어오면 도장만. 50km를 넘긴 다음 날 처음 열 때 4번째 칸 자물쇠가 풀리며 물건이 톡 떨어지는가(한 번만).
- 0.4~0.45초 값이 짧거나 길면 config `ui.motion`에서 고친다(개발이 고친 값은 note에).
