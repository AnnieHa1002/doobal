## 개발 메모

- 작업 방식: Opus가 계획 → Sonnet 작업자가 워크트리에서 구현 → Opus가 검토·테스트 → `dev-batch`에 fast-forward/merge → `git push origin dev-batch:main`(메인 폴더 main도 맞춤). 세션 끝에 커밋·push, `dev-batch`는 하루 한 번 main에 합친다(11/1 작업 규칙).
- `dart format`은 쓰지 않는다(손으로 약 100자).
- 글꼴(11/4): 개구 Bold 1.6MB·동글 Bold 0.8MB·고운 바탕 Bold 1.4MB·고운 돋움 1.2MB = 약 4.8MB(줄이기 전 11.5MB). 문구·데이터에 새 글자가 생기면 tools/subset_fonts.py를 다시 돌린다(원본 폴더에 개구·동글·고운 원본, fonttools는 작업 폴더 밖 venv). 개구에는 · × … → ① 같은 기호가 없어서 표시 글꼴은 고운 바탕으로 대신 그린다(fontFamilyFallback). 고운 바탕 Regular는 뺐다.
- 빌드 경고(11/4): app_settings·health·pedometer·rive_native·workmanager_android가 Kotlin Gradle Plugin을 써서 ‘앞으로의 Flutter에서 빌드 실패’ 경고가 난다. 지금은 빌드된다. Flutter를 올리기 전에 이 플러그인들의 새 판을 확인한다.
- config는 손으로 고친다: 11/4 sync.backgroundMin 15를 더했다 (개발 기획 데이터 v6 config로 바꿀 때 이 키를 남긴다).
- 꾸미기 탭 줄은 글자 배율 1.5배 상한(작은 화면·글자 2배·동글에서 아래가 넘쳐서).
- 꾸미기 머리·피부 탭은 숨겼고(11/4) 테스트는 decorate_screen_test의 ‘(숨김)’ 묶음에서 탭만 따로 띄워 본다. 정령을 상자에 세우는 것은 SpiritStanding(쉼터와 같은 키 잣대).
- 화면이 꺼진 Mac에서 전체 테스트가 멈추면: `flutter test --timeout 120s test/domain test/app test/data test/widget_test.dart` 한 번 + `test/ui/*_test.dart`를 파일마다 따로.
- 테스트는 rive_native macOS 라이브러리가 있어야 돈다. 새 워크트리에서는 메인 폴더의 것을 복사한다:
  `mkdir -p app/build/rive_native/native/build/macosx/bin/debug_shared && cp <메인 폴더>/app/build/rive_native/native/build/macosx/bin/debug_shared/librive_native.dylib app/build/rive_native/native/build/macosx/bin/debug_shared/`
- 실기기: `flutter run -d adb-R3CX706ENER-B6XyNv._adb-tls-connect._tcp`(무선). 폰이 잠들면 ‘Width is zero’로 멈추니 잠금을 풀어 달라고 한다. 디버그 APK 약 340MB라 설치에 30초 넘게 걸린다.
- 안드로이드 SDK `~/Library/Android/sdk`, JDK temurin-21(`flutter config --jdk-dir`).
- Health Connect: 삼성 헬스가 Health Connect에 걸음 쓰기(WRITE_STEPS)를 켜야 들어오고, 몇 분씩 몰아서 들어온다. 그래서 걷는 중 숫자는 기기 걸음 센서, 진행·보상 기준은 health.
