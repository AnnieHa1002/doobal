- 쉼터: 20~40초마다 떠 있기 ↔ 앉기 정면·옆이 끊김 없이 바뀌는가(앉기는 그림자가 몸에 붙음), 밤(일몰 1시간쯤 뒤)에 누워 자며 졸린 얼굴인가, 아침에 깨는가. 누르면 행복 1초, 3초 안 5번이면 화남 2초.
- 걷는 중: 정령이 걷는 쪽(오른쪽)을 보는가, 멈추면 둥둥 옆(오른쪽), 동행·물감 방울이 정령 발과 맞는가. **휴대폰을 가로로 돌리면 걷는 중만 가로**, 쉼터·노트·상점은 세로 그대로. iOS(아이폰)도. 아이패드는 방향 설정을 손대지 않아 잠금이 안 먹을 수 있다.
- 길 위 만남: 놀람 + 인사가 어색하지 않은가(인사 동안 잠깐 정면).
- 도착: 액자 오른쪽 아래 작은 정령이 잘리지 않는가(모자·떠 있는 소품은 상자 56×90 밖이면 잘림), 그림이 다 나타나면 기뻐하는가.
- 꾸미기: 미리보기를 밀어 정면·옆·뒤, 머리·배 누르기와 헷갈리지 않는가.
- 상점: 지름길·순풍 꼬리표의 설명 두 줄, 글자 크게. 여행 모자 등 기본 소품을 얻으면 쉼터 수레에 점, 앱을 껐다 켜도 남고, 상점을 열면 꺼짐. 이 판으로 올린 직후(18 → 19)에는 점이 없어야 한다.
- 노트 걷기 기록: 날짜 카드, 붓 아이콘, ‘오전 8:05’, 글자 크게. 오늘 줄이 없고 다음 날 새벽 5시 뒤에 생기는가.
- 정령 만들기: 처음 골라져 있는 여행복 색이 설치할 때마다 4색 중 하나인가.
- 방명록: 금칙어가 들어간 글을 남기면 ‘금칙어가 포함되어 있어요’(에뮬레이터 서버).

## 통합 세션이 합칠 때

- **config·데이터**: 손대지 않음. `Rules.screen`(`ScreenRules.fromJson(j)`, 생성자 인자 `screen` 하나 — T12의 `paintColor` 바로 뒤)이 v22 `ui.newDot`·`ui.orientation`·`character.rive`를 읽는다. 틀린 값(모르는 자세 이름, 모르는 `newDot` 자리, `restSwap` minSec > maxSec, `orientation.others` ≠ portrait, 빈 `customizePreview.swipe`)은 FormatException → 앱이 config를 못 읽는다. `SpiritPalette.cues`는 palette `customPartsV33`가 있을 때만(없으면 빈 표 → 표정 없이 동작만).
- **DB 19** = `sync_state.shop_seen_utc`(nullable int) 하나. `app_db.dart`의 `schemaVersion` 19, 마이그레이션 끝 `if (from < 19 && await hasTable('sync_state'))`: 열이 없으면 더하고 `COALESCE((SELECT MAX(unlocked_utc) FROM props_owned), install_utc)`로 채움. 18의 `lacks` 도우미를 `onUpgrade` 맨 위(`hasTable`·`lacks`)로 올려 18·19가 같이 쓴다(18 동작 그대로). `app_db.g.dart`는 build_runner로 다시 만듦. 시험 `test/data/app_db_test.dart`: `_userVersion(db), 19`(18곳)·제목 ‘19로’(18곳)·sync_state 열 목록 3곳에 `shop_seen_utc`, 새 시험 셋(18 → 19 소품 있음 = 마지막 얻은 시각 900, 소품 없음 = 설치 시각, 새 DB는 null). `test/app/backup_service_test.dart` 머리 schema 19. **백업 형식은 그대로**(sync_state는 백업에 안 넣는 표). 다른 트랙이 같은 때 DB를 올렸으면 번호가 부딪힌다(통합 세션 말로는 지금 없음).
