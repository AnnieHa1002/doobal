## 크기

- 쉼터 물품: PNG 3,432KB → `tools/to_webp.py --write --remove-png`(장마다 ssimulacra2 ≥ 85·butteraugli ≤ 0.75로 품질 고름) → WebP 576KB(q88~q92). 해상도는 납품 캔버스 그대로(decor.json 좌표가 캔버스 px라서). 그리는 크기는 캔버스의 약 35~76%(3배 화면, bboxPx 배율)이고 쉼터는 확대가 되어 줄이지 않았다. 메모리는 `cacheWidth`로 그리는 크기만큼만 푼다(T15 코드).
- 아이콘: 192px 내보내기를 씀(옆 버튼 44pt·탭 28pt = 3배 화면에서 132·84px라 192로 충분). 512는 넣지 않음. 옆 버튼 q80~q82, 탭 마스크는 무손실.
- 늘어난 앱 그림: **616,918바이트(약 0.59MB)** = 물품 12장 576KB + 옆 버튼 17.3KB + 탭 3.7KB + 무늬 5.5KB. 늘어난 뒤 assets 폴더 전체 69,543,263바이트(66.3MB)의 약 0.9%. WebP는 앱 묶음에서 더 압축되지 않아 내려받기 크기도 거의 같게 는다(추정).

## 판단

1. **아이콘 이름**: 받은 192 파일 이름(`..._v01_192_clean`)은 `AssetIndex.sprite` 규칙(`이름(_vN)(_clean)`)에 안 맞아 `..._v01_clean.webp`로 넣었다. 512판은 Drive에 원본이 있다.
2. **탭 아이콘은 흰 마스크**(납품 color_mode grayscale)라 색을 입힌다. 색은 지금 코드 그림과 같게: 쉼터 = 지금 탭 잉크·아닐 때 옅은 잉크, 걷기 발자국 = 지금 탭 테라코타·아닐 때 옅은 잉크. 텐트 안 채움(#e6c99a)·불 테라코타처럼 두 색으로 칠하던 것은 한 색이 된다.
3. **걷는 중 발자국**: 캔버스 움직임(0.9초에 왼발·오른발 번갈아, 꺼진 발 25%) 그대로. 두 발 그림(walk)을 25%로 깔고 step1·step2를 번갈아 켠다. step3은 walk와 같은 그림(SHA256 같음)이라 넣지 않았다. config `walkingFrames` 세 장을 차례로 넘기는 방식(왼발 → 오른발 → 두 발)은 쓰지 않음.
4. **상점 옆 버튼**: 수레 그림 대신 납품 아이콘(가게 차양)으로 바뀐다. 수레 그림은 아이콘이 없을 때만.
5. **옛 옆 버튼 그림** `obj_rest_{map,backpack}_v11_clean.png`(배경 폴더)는 이제 아이콘이 없을 때만 쓰여 남겨 뒀다. `obj_rest_note_v11_clean.png`은 코드에서 안 쓴다(시험 fixture만). 셋을 빼면 앱 그림이 339,303바이트(약 331KB) 준다 — 아래 제안 2.
6. 수레 종류 아이콘(v01)·배 색 층 그림은 받지 않아 넣지 않았다.
