# 정령 애니메이션 v23 (2026-11-03)

승인된 v17 캐릭터와 v18 일곱 포즈, v20 정면 머리·배 눌림을 네이티브 Rive 벡터로 옮겼다. 기본 몸에 선택형 여행 망토를 추가했다. 기본 몸은 그대로 유지하며 다른 소품은 아직 포함하지 않는다.

## 실제 앱 연결

- `assets/rive/doobal_spirit.riv` → `SpiritCharacter` → `SpiritController`.
- `DoobalCharacter`는 기존 속도·DoobalPose 호출을 받아 정령으로 표시한다. 기존 사람형 자산과 DoobalController/DoobalItemArt는 기존 시험·복구용으로 보존한다.
- SceneView 기준: 캔버스 600×600, 가운데 x300, 머리 위 y150, 발바닥 y440. 기존 시간대 색 보정과 배경/전경 순서 유지.
- 속도 0 서기, 0 초과 걷기, 1.5 이상 달리기. 쉼터 앉기, 배 위는 서기. 걷기 진행과 화면 이동은 기존 앱 소관이다.
- 개발 화면의 **정령 움직임**에서 일곱 동작과 실제 머리/배 터치를 시험한다.

## 제어

Artboard `DoobalSpirit`, State Machine `SpiritController`, View Model `DoobalSpirit`.

| motion | 동작 |
|---|---|
| 0 | 기본 서기 |
| 1 | 옆으로 걷기 |
| 2 | 앉아서 쉬기 |
| 3 | 눕기 |
| 4 | 점프(보조 동작) |
| 5 | 달리기 |
| 6 | 누워서 자기 |
| 7 | 손 흔들기 |
| 8 | 넘어졌다 일어나기 |
| 9 | 웃기 |

`controller.play(SpiritMotion.wave)` 등으로 호출한다. 손 흔들기·넘어지기·웃기·점프는 끝나면 최신 장면 동작으로 복귀한다. 넘어지기 등의 자동 발생 제품 규칙은 추가하지 않았다.

`direction`: 0 정면, 1 오른쪽, 2 뒷면, 3 왼쪽. `expression`: 0~5. `noseStyle`: 0~3. `lookX/Y`: -1~1.

`headPressed`, `bellyPressed`는 독립 Boolean이다. Rive 내부의 몸을 따라가는 영역과 Flutter 실제 포인터를 연결한다. 누르는 동안 유지하고, 손을 떼거나 영역 밖으로 나가거나 취소되면 34프레임 동안 복원한다. 앱은 누르는 동안 이동을 멈추고, 정면으로 돌려 반응한 뒤 0.6초 후 최신 장면 동작을 복구한다. 앱이 백그라운드로 가도 눌림을 해제한다. 동시에 두 부위를 누르면 머리 반응을 우선한다.
