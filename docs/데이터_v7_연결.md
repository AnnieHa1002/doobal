# 데이터 v7 연결 점검표 (2026-11-04, 개발 기획 → 개발)

브랜치 `data-v7`의 데이터(config v8 · palette v6 · props v4 · landmarks v3 · shop v4 · boats v2 · scene v4 · themes/camp v2 · moderation v1)를 dev-batch 코드에 붙일 때 고칠 곳. 리포 코드(dev-batch 7a410fb)를 읽고 대조했다. 실행해 보지 않았으므로 "깨질 것"은 코드 읽기 기준 추정.
명세는 M2~M6 명세 v0.11 머리 블록 ①~⑬, 정적 데이터 스키마 v7.1.

## 1. 앱 시작이 깨질 것 (먼저)

| 파일 | 코드 | 문제 | 고칠 것 |
|---|---|---|---|
| config.json | `domain/rules.dart` `SceneLayerId { sky, backdrop, ridge, grove, meadow, ground, foreground }` | scene.layers에 `ridge`가 없고 `roadside`·`people`이 있음 → '모르는 레이어: roadside' / '레이어 규격이 없다: ridge' | SceneLayerId를 v4 6역할로: sky·backdrop·grove·roadside·meadow·ground·foreground. `people`은 레이어가 아니라 roadside 안의 조각 묶음이라 layers 파싱에서 건너뜀(speed 없음). seaHiddenLayers도 roadside 포함 |
| config.json | rules.dart 레이어 값 | backdrop 1764×662 → 4800×1230 y 912(v10), grove 속도 0.3 → 0.1, ridge 값 없음 | scene_art.json(v12)이 실제로 그리고 있으면 그 값과 대조해 하나로. 남는 쪽은 scene.json v4(데이터 원본) |
| palette.json | `domain/look_palette.dart` `json['hair']`·`json['skin']`·`gradient` | v6에서 hair·skin은 `legacy` 아래로 옮김 → null 캐스트 | 정령 전환과 같이: `body{base 200, swatches 10, default 1}` 하나로 읽기. 그전까지 임시로 `legacy.hair/skin`을 읽게 바꿔도 됨 |
| props.json | `domain/prop.dart` 해금 switch | `shop` 종류가 없음 → '모르는 소품 해금 조건: shop' | `PropUnlockKind.shop`(price) 추가. 꾸미기에는 산 것만 보임 |
| props.json | `doobal_item_art.dart`·`doobal_controller.dart`·`format.dart` 슬롯 | 사람형 슬롯(hand=손에 드는 것, pet=어깨 친구). v4는 정령 슬롯 9(hat·face·cloth·shoe·hand·bag·pet·float·effect) | 꾸미기 정령 전환 때 슬롯 9로. 화면 이름: pet = '미니 친구', float = '둥실', face = '얼굴 소품', effect = '효과' |
| themes/camp.json | `domain/camp_theme.dart` | v2는 x가 **장면 폭** 비율, `cart` 물건·`campfire`·`hitOrder`·`sceneWidthRatio` 추가, `note` id 그대로 | 넓은 쉼터(가로 스크롤) 구현 때 x × 장면 폭. 그전에 v2를 읽으면 물건이 왼쪽으로 몰림 → v1 값이 필요하면 쉼터 넓히기와 같이 넣기 |

config v8에서 미리 맞춰 둔 것(코드 고칠 필요 없음): `sync.aliveSaveSec` 30 되살림, `bonus.appliesTo` = `qualifiedSession`.

## 2. 새 키 (읽지 않아도 안 깨짐, 기능 만들 때)

- config `coins.perKm` 10이 들어옴 → **지금 코드의 럭 적립이 켜짐**(v2는 null이라 꺼져 있었음). 하루 상한 400·첫 선물 100(`coins.dailyCap`·`welcomeGift`)을 아직 안 읽으면 상한 없이 쌓이니 같이 넣기.
- config `character.canvas`(1024·발 960), `character.tapReaction`(3초 5번 → 2초 화남), `coins.format`('500 럭'·'+12 럭'), `ui.displayFonts`(개구 1.3·동글 1.5·고운 바탕 1.0), `ui.fontPt`(최소 11), `ui.splash`, `rest`, `guestbook`(신고 키, `blindMinX`·`xMinTotalSteps` 폐기 — 코드는 안 읽고 있음).
- palette `rive`(v24 View model 이름·정수표), `customParts`(id ↔ rive 정수, **noseStyle은 0 고리·3 없음**), `expressionTriggers`, `tintProps.hat_01`.
- props `tint`(hat_01), `float_02` 몽실 구름·`float_03` 꼬마 열기구(hand_03·04 삭제).
- landmarks `firstPainting`·`note`(kr088 '산불 이전 모습') — 도착·화집에서 painting 대신 firstPainting.
- shop.json(상점 M4.5), boats.json(배 9척, islandArrival 판정, layers·발 자리), scene.json v4(scene_art.json v12와 합치기).
- moderation.json·moderation_cases.json: `domain/moderation.dart`가 이 파일을 읽고 `data/check_moderation.py`와 같은 순서로 검사, cases 100개를 테스트로.

## 3. DB (Drift) — 버전 올릴 것

- Profile.look: 얼굴 값을 문자 id로(eyes·brows·nose·mouth), `tints{propId: swatch|custom}`, slots 9. 출시 전이라 옛 값은 기본 얼굴(dot·shiba·shy·omega)·크림으로 초기화.
- Profile.boatId(기본 boat_raft), Profile.displayFont(gaegu 기본).
- 얻은 배 기록(boat_raft는 처음부터).
- 백업에 위 값 포함.

## 4. 순서 추천 (추정 공수)

1. 시작이 깨지는 것 1장(레이어 id·palette 읽기·shop 해금) — 약 0.5일
2. 럭 상한·첫 선물(coins.perKm가 켜지므로 같은 커밋에서) — 약 0.5일
3. 테스트 2,296개 돌려 실패를 데이터 탓/코드 탓으로 나눔 → data-v7을 dev-batch에 합침
4. 나머지는 15장 [개발] 다음 할 일 순서대로(꾸미기 정령 전환, 상점, 쉼터 넓히기 …)
