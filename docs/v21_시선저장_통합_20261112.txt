두발 게임 본체 — v21 동작 + 시선·저장 통합 v05 (2026-11-12)

확인한 납품: 행동 리깅 채팅의 얼굴 선택 v21 완료 보고와 output/spirit_face_selection_v21_20261112의 원본 프로젝트·Android 검증 기록.
v21 원본과 다른 채팅 작업 폴더를 수정하지 않고 별도 프로젝트를 만들었다.

그림/동작: v21의 7자세(떠 있기 정면·옆, 앉기 정면·옆, 잠들기, 뒷모습, 이동 옆)와 반응 5개, 37소품·색 입력을 사용한다. v21 애니메이션 7개와 상태 전환은 보존했다. 동작 개수와 애니메이션 트랙 개수는 다르다. v21은 이전 분리 호흡/다리 트랙을 IdleMicroAndBlink에 통합한 구조다.
시선: 기존 ±1 제한, 열린 검은 눈 4×3px / 외곽선 있는 눈동자3×2px. 정면·옆·앉기·이동과 기쁨/화남의 선택 눈에 적용한다. 감은 눈·잠들기 눈 고정. 손을 떼거나 마우스가 벗어나면 기존 게임 처리대로 중앙 복귀.
저장: 기존 Look 문자ID, 레거시ID 대응, DB 스키마, 얼굴 목록, 몸색, 소품37종 색과 장착, ProfileService를 유지했다. v21 시험 앱의 휘발성 저장은 가져오지 않았다. 시선 자체는 저장하지 않는 순간 상호작용이다.

입력 변환: 게임 모델의 0기준 눈/코/입 번호를 v21 Rive 번호에 대응한다.
eye = game.eye+1, brow = game.brow, nose = game.nose==7 ? 0 : game.nose+1, mouth = game.mouth+1.
따라서 예전 프로필의 눈썹·코 없음도 그대로다. 기본 얼굴 v21=1/1/7/7.
poseChoice 0정면·1옆·2앉기정면·3앉기옆·4잠들기·5뒷모습·6이동옆.
이제 게임 walk/run은 단순 옆 부유1 대신 실제 이동6, direction2는 뒷모습5를 쓴다.
기쁨은 v21의 선택 눈/눈썹/코 + 큰미소, 화남은 선택 눈/코 + 화난눈썹(없음 유지)/입을 잠시 쓰고 원래 선택으로 돌아간다.

게임에서 바꾼 파일: spirit_controller.dart, palette.json의 Rive 설명, doobal_unified.riv, 관련 런타임 검사. 얼굴·색·소품 저장 모델과 포인터 이벤트 코드는 그대로다.
검증 상세는 검증결과.json 및 checks 폴더 로그에 기록한다. Android 분리 시험 앱 com.annieha.doobal.integration에서 실행하며 실제 게임 앱을 덮어쓰는 설치는 하지 않는다. 실기기 성능·배포·커밋/push는 하지 않았다.
