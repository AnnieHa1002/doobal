## 2. 입력 (모두 뷰 모델 속성, 상태 머신 입력 아님)

| 속성 | 값 | 앱이 넣는 곳 |
|---|---|---|
| poseChoice | 0 둥둥 정면 · 1 둥둥 옆 · 2 앉기 정면 · 3 앉기 옆 · 4 누운 잠들기 · 5 둥둥 뒤 · 6 옆 이동 | 3장 화면별 자세 |
| eye 1~6 · brow 0~6 · nose 0~7 · mouth 1~8 | 0 = 없음(눈썹·코만) | 모습 얼굴(palette `customPartsV33`) |
| expr | 0 기본 · 1 행복 · 2 놀람 · 3 울먹임 · 4 졸림 · 5 화남 | 4장 |
| 트리거 | greet · joy · tapHead · tapBelly · angry · resetMotion | 4장 |
| 소품 Choice | hatChoice 0~4, faceChoice 0~3, cloth·shoe·hand·bag·pet·floatChoice 0~5 (0 = 안 입음) | 모습 슬롯(props `rive.n`) |
| 색 | bodyColor + 소품 37개 `<이름>Color`(합 38) | 몸 색·소품 색(5장) |

- 자세는 poseChoice만 바꾸면 riv가 전환한다. 앱이 두 그림을 겹쳐 흐리기 하지 않고, 같은 인스턴스를 계속 쓴다(입력 값이 이어짐).
- 옆모습(1·3·6)은 왼쪽을 본다. 오른쪽으로 걷는 걷는 중 화면에서는 좌우 뒤집기(config `flipSideOn`).
- 다리 달랑·작은 움직임(숨쉬기·팔 톡·눈썹 들썩·고개 갸웃·깜빡임)은 riv 몫이라 앱 입력 없음.

## 3. 화면별 자세 (config `character.rive.screens`)

| 화면 | 자세 |
|---|---|
| 쉼터 | 떠 있기 정면·앉기 정면·앉기 옆을 20~40초마다 무작위(같은 자세 연속 없음, 가안 `restSwap`) |
| 쉼터 밤 | 누운 잠들기(4) + expr 졸림 |
| 걷는 중 | 옆 이동(6), 걸음이 멈춰 있을 때는 둥둥 옆(1). 좌우 뒤집기 |
| 도착·꾸미기·정령 만들기(1-2 나)·나의 정보 | 둥둥 정면(0) |
| 출발 순간·스플래시·풍경 보기·이야기 그림 | 둥둥 뒤(5) |

- '밤' 판정은 하늘 키 시각의 night 구간(config scene.sky).
- 이야기 그림(story_layers) 정령은 둥둥 뒤 한 장. 배율은 5장 크기 규칙 뒤에 다시 잼.
- 11/13 물감 길 결정으로 출발 버튼이 없어지면 '출발 순간'은 걷는 중으로 넘어가는 순간으로 읽는다(C 묶음 때 다시 확인).

## 4. 표정·트리거

| 일 | 넣는 것 |
|---|---|
| 도착·그림 받기·선물·새 소품 | joy 트리거 + expr 1, holdSec 뒤 0 |
| 만남·출발 | greet |
| 머리 누르기 / 배 누르기 | tapHead / tapBelly. 판정 가안: 아트보드 위에서 45% 안 = 머리, 그 아래 정령 몸 = 배(config `hit`, 폰에서 확인) |
| 3초 안 5번 연타 | angry + expr 5, 2초 뒤 0(config tapReaction) |
| 동행 이야기 감동·오래 쉬다 돌아옴 | expr 3 |
| 밤 쉼터 | expr 4. 끝낼 때 0으로 되돌림 |
| 화면을 떠날 때 | resetMotion |

- expr 번호가 v24와 다르다: 놀람 2·울먹임 3(v24는 울먹임 2·놀람 3). palette `customPartsV33.expressions`가 새 표.
- 화남 빠직·잠들기 자는 눈·졸림 때 고른 눈썹 유지는 riv가 그린다.
- 넘어지기는 없다(11/6).

## 5. 모습 → 입력

- 얼굴: 저장값 id(e1~e6, none·b1~b6, none·n1~n7, m1~m8) → rive 번호. 기본 얼굴 e1·b1·n7·m7. 옛 v24 얼굴 값은 기본 얼굴로 초기화(출시 전, DB 버전 올림).
- 몸 색: palette body 견본 hex(또는 직접 고른 hex)를 bodyColor에 그대로. 색 계산(밝기 기준 등)은 riv 안이라 앱은 hex만 넘김.
- 소품: props.json v8 `rive` = {choice, n, color}. 슬롯마다 `<choice>` = n(안 입으면 0), 그 소품 색을 `<color>`에. 색 소품(variantOf)은 기본 소품과 같은 n + 자기 material.hex. 그 밖의 소품은 riv 기본 색 그대로(앱이 넣지 않음).
- 여행복 = clothChoice 4, 시작 색 4(카키 #C0A475·크림·살구·라벤더 #D3C6E6)는 travelVestColor에 그대로.
- 효과 슬롯(effect)은 Rive 밖, 앱 입자(CustomPainter, codex_effects_v01 조각).
- 번호·색 이름의 출처: 번호는 소품 아이콘 README 순서(v32에서 Choice를 차례로 입혀 뽑은 순서, clothChoice 4 = 여행복이 인계 문서와 맞음), 색 이름은 영어 이름의 camelCase + Color(인계 문서 예 beretColor·travelVestColor와 같은 규칙). **inputs.md와 대조 전**이라 props `rive.riveVerified false`. 개발이 riv를 열어 속성 목록을 뽑아 맞춰 보고, 다르면 build_static.py RIVE_ORDER·_camel만 고친다.
- 옷 색 식(neutral × 색 ÷ 180 → ÷ 200, 11/11 디자인 기획 질문)의 답: 앱은 식을 쓰지 않고 hex만 넘긴다. riv 안의 기준값을 200으로 할지는 디자인 기획이 정하면 됨(개발 기획 쪽 제약 없음, 견본과 같아 보이는 쪽 추천).

## 6. 크기

- 정령 키 = 동행 키 × 0.75(16장 11/9, 그대로). 동행 Rive v15 크기는 그대로.
- 화면에서 정할 값은 '아트보드 600px 안 정령 몸 키'에 대한 배율 하나. v33 qa 그림에서 서 있는 정령 몸 키(px)를 재면: 화면 배율 = (동행 화면 키 × 0.75) ÷ 그 몸 키. 지금 config `character.float.screenHeightPx` 344/259px는 v0.3 추정값이라 그때 다시 정함.
- 떠 있기 높이·그림자·앉기에서 그림자 붙음은 riv 몫(앱 lift·그림자 타원 없음).
- 쉼터 자리(camp_wide `characterFloat` 가안 115pt)·배 위·이야기 그림 배율은 같은 몸 키로 다시 계산.

## 7. 앱 쪽 (개발, T5)

- Rive v25 연결 코드(SpiritController)를 고쳐 쓴다: 파일·아트보드·뷰 모델 이름, 입력 표(2장), 자세(3장), 표정 번호(4장), 얼굴·소품·색(5장).
- 미리 읽기: 쉼터·걷는 중·꾸미기에서 같은 인스턴스. 11.8MB 파일은 앱 시작 때 한 번 읽어 둠(메모리 실측).
- 테스트: 화면 → 자세 번호, 쉼터 restSwap 같은 자세 연속 없음·20~40초·밤 4, 연타 → angry, expr 표, 얼굴 id ↔ 번호, 슬롯 → Choice·색(색 소품은 기본 번호 + 자기 hex), 효과는 Rive에 안 넘김, 옆모습 걷는 중 뒤집기.
- 완료 기준: 중급 안드로이드 쉼터·걷는 중 60fps, 자세 바꿀 때 끊김 없음.
