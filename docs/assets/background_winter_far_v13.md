# 두발 겨울 후경 v13

2026-11-03. 기존 v10 후경 7지역을 편집한 겨울 제작본. 정지 이미지·파일 검수 완료, 앱 합성·실기기 최종 확인 대기.

## 사용 파일
- clean/: 6144×1536 RGBA PNG 7장. 수도권·강원·충청·전라·경상·제주·바다.
- tiles/: 원본별 2048×1536 분할 3장씩, 총21장. part1→part2→part3 순서.
- qa/: 원본/겨울 비교(원본 위·겨울 아래), 충청·전라 연결부 전후(수정 전 왼쪽·수정 후 오른쪽), 담수 결빙 전후 3장(위 수정 전·아래 수정 후), 반복 경계, 수치 기록.
- src/: 생성 원본·프롬프트·정리 스크립트 묶음. 원본 v10 PNG는 기존 Drive 폴더에 보존하며 manifest에 ID·SHA256 기록.

## 그림 방향
원본의 가는 갈색 윤곽, 큰 색면, 숲 군락 형태를 따른다. 지난 시안의 세밀한 나뭇가지 묘사는 쓰지 않았다. 강원·경상은 넓은 적설, 충청·전라는 논·들판의 얇은 눈, 제주는 한라산/오름 윗면만 눈. 사용자 피드백(11/3)에 따라 충청 호수·전라 강/수로·경상 강은 옅은 청백색 얼음으로 보완했다. 전라의 먼 바다와 제주·바다 지역의 해수는 얼리지 않는다. 하늘은 투명.

## 제작 방법과 한계
창작 편집은 내장 imagegen. 원본6144×1536의 위아래에 투명256px씩을 넣어3:1 작업 입력으로 사용했다. 생성 결과2172×724를 정규화·확대하고 패딩을 제거해6144×1536으로 내보냈다. 6144px 네이티브 생성이라고 주장하지 않는다.
원본 외곽 알파를 복원하고 낮은 알파 먼지를 정리했다. 양끝64px RGB 경계를 연결했다. 충청·전라는 x3950~4249 연결부를 imagegen으로 보완했으며, 연결부 단계에서는 이 좁은 구간 밖 픽셀을 보존했다. 그 뒤 담수 결빙 단계에서 imagegen 결과를 기존 물 영역 안에만 합성했다(가장자리 약2px 완화·반복 양끝 RGB 정규화). 이 단계에서 육지와 외곽 알파는 보존하며 전라의 먼 바다는 마스크에서 제외했다. 연결부를 제외한 외곽 마스크는 원본 기준이다. 내부 세부 선까지 원본과 픽셀 단위로 같다는 뜻은 아니다.

## 확인 결과
7장 모두6144×1536 RGBA. 알파1~24 픽셀0. 좌우 마지막/첫열 RGBA 차이0. 분할21장을 재조립하면 각 원본과 픽셀 동일. 원본/겨울과 연결부 전후 시각 확인.
앱·Rive·실기기에서 걷는 중 가로/세로 합성과 시간대 전환은 검수하지 않았다. 캐릭터 원화 작업은 보류 상태라 새 캐릭터 제작도 하지 않았다. 사용자의 최종 그림체 채택 전 기존 v10을 자동 교체하지 않는다.

## 연결 참고
겨울은12~2월. 기존 후경과 동일 위치·크기를 사용한다(세로4800×1230,y912; 바다 높이1280). 이 패키지는 앱 scene.json이나 계절 판정 코드를 수정하지 않는다. 기존 v10/v11 배경 파일도 변경하지 않는다.
