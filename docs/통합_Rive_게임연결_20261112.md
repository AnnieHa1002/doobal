# 확정 통합 Rive 게임 연결 (2026-11-12)

- 게임 파일: `app/assets/rive/doobal_unified.riv`. 원본은 이 채팅의 v03 통합본(옆앉기 v18 다리 포함)이다. 검토판 버튼·바탕만 제거한 투명 내보내기이며 캐릭터와 동작 곡선은 보존했다.
- 상태 머신 `WardrobeController`, View Model `WardrobeColors`. 게임의 기존 `SpiritController` API를 유지하면서 새 입력으로 대응한다. 보행·달리기는 확정 옆면 부유, 앉기는 앞/옆, 눕기·잠들기는18도 자기, 인사는greet, 기쁨은joy, 터치는tapHead/tapBelly, 연타는angry다. 확정본에 없는 넘어짐은 기본 부유로 대응한다.
- 꾸미기 미리보기: 기본·기쁨·인사·배 눌림·잠들기·화남·머리 눌림. 같은 단추를 다시 눌러 재생할 수 있다. 동작 선택은 프로필에 저장하지 않는다.
- 소품37개: `unified_wardrobe.dart`에서 게임 id를8개 칸 선택과37개 색 입력으로 대응한다. 효과 슬롯·동행 시스템·보유/해금 조건은 기존 게임 코드 그대로다.
- 색: 몸은 기존 `Look.body`, 소품 색은 `Look.propColors`의 `{기본소품id: #RRGGBB}`. 색별 소품과 시작 여행복 색도 해당 채색 면에 반영하며, 직접 고른 소품 색이 우선이다. 몸 색을 바꿔도 선과 다른 소품에 필터가 걸리지 않는다.
- 저장: 기존 꾸미기의 **저장** 단추 → `ProfileService.saveLook` → 기존 Drift `profile.look` JSON. 별도 시험 앱의JSON파일은 사용하지 않는다. DB 스키마 변경 없음. 새 키가 없는 기존 저장을 읽고, 색 하나가 잘못돼도 기존 소품·프로필 전체를 초기화하지 않는다. 닉네임·걸음·여정·보유 소품은 수정하지 않는다.
- 2026-11-12 후속 갱신: 확정 PSD 얼굴 부위 선택·시선 입력을 통합 v04에 연결했다. 기존 저장값 대응과 검증은 `얼굴_파츠_시선_연결_20261112.md` 참고.
